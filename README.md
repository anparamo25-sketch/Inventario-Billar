# Inventario Billar

Sistema Android para control de inventario, freezer, ventas y arqueo.

## Funciones base

- Bodega por cajillas y unidades equivalentes.
- Freezer por unidades.
- Movimientos bodega -> freezer en unidades.
- Cierre de jornada mediante conteo final de freezer.
- Cálculo automático de unidades vendidas y dinero.
- Préstamos/retiros de dueños.
- Consumos de dueños.
- Arqueo antes de rellenar freezer.
- Rellenar freezer como último paso.
- Historial diario organizado por mes.
- Reportes PDF quincenales.
